# 从0到1成为合格交易员-作者系列总目录与学习顺序

## 整理要点

作者将读图、入场、突破、实盘复盘汇成总目录，并列出未来计划。已发表课程与计划中的内容分开；保留“不能保证学完赚钱”和需要大量练习的边界。下方本地入口由整理者依据原帖ID匹配，不改变作者原目录。

## 作者原文

最近经常有人问我：读图篇在哪里？H1、H2 怎么数？信号 K、假突破、缺口是哪一篇？

这些内容前前后后写了快两个月，有些发的是长文，有些是普通帖子，中间还夹着复盘和实盘案例。老粉一路看过来还好，新关注我的朋友想从头学，确实很难找。所以我重新整理了一遍。

以后这一篇就是《从0到1成为一名合格的交易员》系列的总目录。已经写完的内容都放在下面，后面每更新一课，我也会继续把链接补进来。

为什么要写这个系列？
X 上从来不缺喊单，也不缺告诉你“这里买、那里卖”的人。行情大涨的时候，大家担心踏空，行情突然下跌，又不知道该止损、补仓还是继续等。看了很多分析，真轮到自己下单时，还是不知道图上发生了什么。

问题并不在于少看了一个指标，而是没有形成自己的交易能力。
受到@cluec3 和@yijiangren  老师的鼓励，我想用比较长的时间，把自己原来学到的价格行为一点点写出来，自己也复习一遍。

Pa学起来其实很快，但需要大量的练习。学会的是理论，但交易的时候，我们能不能从理论知识结合瞬息万变的市场给出正确的判断，以及面对持仓时浮盈浮亏的压力能否保持冷静的心态，这些都是需要不断的练习的。我不能保证谁学完一定赚钱，但至少希望愿意认真学的人，最后能够自己读图、自己判断、自己承担结果。

赚了，是自己的本事。亏了，也知道自己错在哪里。不用再跟着别人的情绪到处跑。

整个系列会按照一笔交易真正发生的顺序来写：
读图 → 判断趋势 → 等待机会 → 选择入场 → 设置止损 → 管理仓位 → 止盈和退出。
目前“读图篇”已经完成，现在正在写“入场篇”的突破专题。后面还会继续写各种订单的使用、反转、楔形、抛物线反转、止损、止盈、仓位和交易管理。
内容会很长，让我们慢慢来。

突破专题完成以后，入场篇还会继续拆这些内容：
回调专题：简单回调、复杂回调、深度回调，以及什么时候不能把震荡当回调。
H1/H2专题：怎样计数、什么时候重新计数、H2为什么通常比H1更稳，以及计数失效的情况。
订单专题：Stop单、Limit单和Market单分别适合什么环境。
反转专题：趋势反转、楔形反转、抛物线楔形，以及为什么很多看起来很漂亮的反转最后仍然会失败。以及一些更高级的入场方式比如M2B/M2S等
再往后是止损、止盈、MM测量，仓位和心态管理等等。

我不准备赶进度，也不会为了更新而更新。一个问题如果一篇写不清楚，就先写一篇长文建立框架，再用几篇短图解解决细节。
建议第一次看的朋友从读图篇01开始，按照顺序往后看。
如果你已经有一些基础，可以直接从自己最容易卡住的地方开始。比如不会判断行情，先看市场周期，总被假突破骗，就看突破专题，方向经常看对却不会入场，可以先看信号 K 和H1、H2。

这篇会长期更新。
建议先收藏。以后找不到某一课，回来翻这一篇就行。

我希望大家有没看明白的地方，或者希望后面单独讲的问题，可以在评论区告诉我。独角戏不好唱，我自己写了半天也不知道写的大家能不能看懂，只要是大家反复遇到的问题，我会慢慢补进这个系列。
