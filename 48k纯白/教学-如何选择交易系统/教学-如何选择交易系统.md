# @48Kchunbai: 刚才在群里和群友聊天时聊到，市面上这么多交易体系，应该怎么选适合自己的？结合我最近看到一张“技术分析流派鄙视链”，谈谈我的看法。

刚才在群里和群友聊天时聊到，市面上这么多交易体系，应该怎么选适合自己的？结合我最近看到一张“技术分析流派鄙视链”，谈谈我的看法。

“鄙视链”里把价格行为、ATR、道氏理论、趋势跟踪排在最上面，ICT/SMC、订单流、均线、MACD、波浪理论也都被分了等级。我是感觉这种排名如果只是比“谁最准”，其实意义不大。交易方法真正的差异，不应该只是技术本身，而是它到底适不适合你这个人。

有人能拿一笔趋势单一个月不动，浮盈回吐20%也无所谓，有人浮盈回吐3%就开始难受（比如我）。有人一天愿意盯盘8小时，有人一天只能看两次盘（比如我）。有人喜欢高杠杆、小止损，10u战神打法，有人最怕连续止损，宁愿低杠杆给行情更大的空间（比如我哈哈）。

所以真正应该选的应该是哪套技术最适合你的性格、持仓周期、杠杆习惯和心理承受能力。我甚至觉得，很多人最后学什么流派，是和人格是有关系的。

比如我是 INTJ，我使用价格行为，就不是偶然，因为我很难接受“金叉买死叉卖”这种答案，我必须要知道为什么这里金叉有效？为什么上一次金叉就被套？前面的市场结构发生了什么？这里到底是趋势、震荡，还是突破失败？一路问下去，最后就很走到了价格行为里。

所以我根据个人粗浅的理解，针对比较流行的流派也列了个大致的适合人群，大家看个乐呵：

流派一：价格行为（SSR）
适合人格：INTJ、INTP、ISTP
我把价格行为放在最上面。但我说的不是那种教你看什么锤头线、吞没线、双底这种简单的图形裸K方法，而是 通过背景 → 趋势/震荡 → 突破 → 回调 → 信号K → 入场 → 止损 → 目标这一套完整的性格行为体系。

我认为它最大的优点是底层逻辑通用、长短通用。股票、黄金、BTC、ES、甲醇期货，几乎什么市场都能用。
它不是靠某一个指标发信号，而是在回答市场现在到底发生了什么？
缺点就是他妈的难，而且非常吃经验。
同一张图，不同水平的人可能看到完全不同的东西。

它特别适合 INTJ、INTP 这种喜欢底层逻辑、概率推演、完整模型的人，也适合 ISTP 这种临场反应快、愿意快速认错的人。
不适合特别讨厌连续止损的人，一单失败了就不想玩了，没时间盯盘，只想等一个明确“买入信号”的人
目前版本价格行为指导员@cluec3 线索c老师 去找他拜师吧～

流派二：趋势跟踪（SSR）
适合人格：ISTJ、INTJ、ESTJ
趋势跟踪是另一个极端。趋势来了就跟，趋势没结束就不走。突破新高买、跌破趋势线走，或者用均线、通道做规则。
它能抓大行情。真正的大牛市、大宗商品趋势、BTC主升浪，一笔单子可能吃几个月。
但胜率往往不高，而且你必须接受大量假突破和浮盈回吐。比如一笔已经赚30%，最后可能只带走10%。

这对很多人心理上非常难。所以它特别适合 ISTJ、INTJ、ESTJ 这种纪律强、愿意执行规则、不需要每天证明自己看对了的人格。

交易风格上，更适合中长线，低杠杆，不喜欢盯盘，能接受连续小亏，能忍浮盈回吐的人
不适合浮盈一回吐就难受的，马上需要知道结果的，高杠杆选手。

流派三：均线系统（SSR）
适合人格：ISTJ、ESTJ、ISFJ

均线其实没有很多人说得那么差。
它最大的特点就两个字：上手容易
小级别均线在大级别均线上就看多，回踩均线找机会，跌破就走。对于很多普通人，这反而比复杂价格行为更容易长期执行。

缺点是有些滞后，需要结合基本面一起判断，而且极度怕震荡。
趋势行情里像神，金叉以后一路涨。
震荡行情里，金叉、死叉、金叉、死叉，来回扇耳光。

所以均线特别适合 ISTJ、ESTJ、ISFJ 这种喜欢明确规则、讨厌模糊判断的人。
适合做波段，中长线不想一直盯盘，喜欢机械规则，容易犹豫的人

不适合最怕连续小亏的，喜欢高胜率的，超短线高杠杆 scalp
如果你心理上特别接受不了：连续错5次，第6次才抓到趋势。那均线趋势系统会很难受。
不过均线派有个掌门人 方外老师 @yijiangren 打的一手无敌的观澜离合双刃，现在版本点位抄作业T0级别的存在 用均线的朋友没有不认识他的。

流派四：订单流 Order Flow（SR）
适合人格：ISTP、ESTP
订单流看的是更微观的东西：DOM/Footprint/Delta/主动买卖成交/吸收/大单成交

价格行为告诉你这里可能有支撑。
订单流进一步看，这里到底有没有真实买盘承接。
它特别适合 ES、NQ、黄金期货这种高流动性市场。
它精确、实时、反馈快。缺点是难！！！信息量太大，而且非常吃数据质量。新手别碰！！

它最像 ISTP、ESTP反应快，喜欢临场决策，不愿意讲太多理论，市场现在发生什么就做什么。
适合做超短线，scalp，高频，高杠杆小止损，每天能盯盘很久的职业交易员，喜欢即时反馈的人

不适合一切新手！！

流派五：ICT / SMC（SR）
适合人格：INFJ、INTJ、ENTP
ICT/SMC 为什么现在这么火，我其实完全能理解。Liquidity、FVG、Order Block、BOS、CHOCH……听起来太爽了太先进了，这才是这个时代应有的交易体系，你们原来那套太老了，哈哈哈哈
它给市场搭了一套完整的故事。学起来会有一种原来机构是在这里扫流动性这种突然看懂市场的感觉。

结构化、视觉化、位置感强。特别适合黄金、外汇、指数、BTC。
缺点是非常容易学成玄学。图走完以后什么都能解释，这里扫了流动性，那里填了FVG，这里是订单块。

但交易真正重要的是，行情没走之前，你能不能下单。而且这里面很多概念，本质上和传统价格行为的突破，假突破，支撑阻力交易区间高度重叠，只是换了一套新的名词听起来更高级。

流派六：威科夫 Wyckoff（SR）
INTJ、INFJ、INTP
威科夫的魅力在于它解释一段行情背后的完整过程吸筹 → 测试 → 拉升 → 派发。

特别适合看中周期结构。但很容易马后炮。行情走完以后看“吸筹、洗盘、弹簧”非常漂亮，实时判断却没那么简单。
适合做中长线股票，愿意慢慢等结构完成的人
不适合高频高杠杆想几分钟解决一笔交易的人

流派七：Volume Profile / 量价分析（R）
适合人格：INTP、ISTP、ISTJ
Volume Profile 看的是市场到底在哪些价格真正成交了大量筹码。
它擅长找成交密集区Value Area/HVN/LVN/市场认可价格
优点是位置感很强。缺点是它更告诉你哪里重要，不告诉你什么时候进。所以最好搭配价格行为。
适合日内做波段，震荡，不喜欢追涨杀跌喜欢等价格回到关键区域的人

RSI / 布林带/
ISFP、INFP、ESFP
这一类更偏均值回归。RSI超买、超卖。布林带离均值远了，可能回来。
它们最大的优势是在震荡行情里高抛低吸。
缺点是趋势来了会把你打的妈都不认识。
强趋势可以一直超买，也可以一直贴着布林上轨走。
所以这一类更适合喜欢高抛低吸、喜欢抓反转、不太喜欢追趋势的人。

ATR：ISTJ、INTJ
ATR其实不应该和其他“流派”放在一起，因为它不算交易系统。
它只回答现在市场正常波动有多大？
但我反而觉得，这是所有杠杆交易者都应该懂的东西。尤其高杠杆p小将。
因为同样10点止损，昨天可能很宽，今天可能连正常噪音都挡不住。
所以 ATR 特别适合做合约高杠杆日内重视风险管理的人
先把风险算清楚，再谈收益。

谐波形态 / 神奇九转 / 江恩：INTP、INFJ、ENFP
这类方法最大的共同点是特别有“结构美感”。
比例、周期、数字、几何关系，看起来非常精确。
容易形成明确规则。很容易过拟合。
历史图里特别漂亮，实盘经常差一点就是完全不同的结果。
不建议学

人格决定你更容易接受哪种决策方式。
找到真正适合自己的交易方法，应该满足三个东西
性格 + 时间 + 风险偏好。
比如：
一个 ESTP，每天能盯6小时盘，又喜欢快速反馈，让他做长期趋势跟踪，他会疯。
一个 ISTJ，每天只有30分钟看盘，让他去学订单流 scalp，也不现实。
一个 INTJ，本身喜欢研究逻辑、愿意花时间训练，那PA的确很容易对胃口。
所以技术分析没有什么绝对的SSR级。真正的SSR，是你愿意长期执行，而且和你的性格不打架的那套方法。

这也是我现在觉得比“哪个指标最准”更重要的一件事。
