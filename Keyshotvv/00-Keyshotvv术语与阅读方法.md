# Keyshotvv术语与阅读方法

这是编辑提供的阅读辅助，方便回看本专题中的作者用语。各篇原文、图表与视频才是具体语境；同一个词在不同阶段可能有不同用法，不将多个时期拼接为一套固定盈利系统。

## 从哪里开始

1. 先看[[00-Keyshotvv交易学习索引|主题索引]]中的基础教学，理解价格结构、均线、流动性与风险单位。
2. 再读同一日期的主帖和“作者后续实质答复”，把问题、答复及条件连起来。
3. 对照配图细读区：区分已经出现的K线、未来手绘箭头、风险回报测量框和真实订单标记。
4. 在[[00-Keyshotvv视频课程索引|视频课程索引]]按系列顺序阅读。先读概念与体系答疑，再看黄金随机复盘、BTC随机复盘及商品案例。
5. 复盘同时记录止损、错过、未成交与保本，不能只摘录盈利案例。收益和胜率按作者自述保存。

## 常见用语

| 用语 | 本专题中的阅读含义 | 容易误读的地方 |
|---|---|---|
| R、盈亏比 | 以某笔初始计划风险为一个单位，比较潜在或实际收益与该风险的比例 | 图形测量6R不等于账户赚6%，移动止损后的比例也不能冒充初始R |
| MA / EMA | 简单/指数移动平均线，用于描述趋势方向、排列、回调或缠绕 | 周期与参数依每篇原文；日线20MA与其他周期均线不能无条件当同一信号 |
| PA | Price Action，作者对价格、K线力度与结构的观察 | 没有脱离具体图形的通用买卖口令 |
| ICT | 作者采用的一组结构、流动性与不平衡概念 | 标注符合术语不代表策略有效性已验证 |
| Sweep / 清扫 | 价格越过旧高、旧低或集中参考位，作者据其后反应解释流动性获取 | 越线后可能延续，也可能回收；清扫本身不保证反转 |
| EQH / EQL | 等高 / 等低；相近高点或低点的参考区域 | 不是所有相近价格都被作者认定为有效等高等低，容差通常未量化 |
| PDH / PDL | 前一交易日高点 / 低点 | 不同市场交易日与时区会改变具体位置 |
| PWH / PWL | 前一周高点 / 低点 | 既可作观察目标，也可作被清扫位置，具体作用依原图 |
| DOL | Draw on Liquidity，作者认为价格可能趋向的流动性目标 | 是方向假设，不能理解为必然吸到该价 |
| ERL / IRL | 区间外部 / 内部流动性参照 | 需要先说明采用哪个区间和周期，不能脱离框架判定内外 |
| BOS | 结构突破；作者据所用波段观察延续或变化 | 单根影线越过不一定满足作者要求，必须看收线与上下文 |
| MSS | 市场结构转变，常与清扫后反向位移结合讨论 | 作者选择的结构层级决定其含义，不把所有小摆动当大趋势反转 |
| CISD | Change in State of Delivery，作者用特定价格越过/收线观察价格推进状态变化 | 具体参考K线及收线要求按该课图示，不补成统一机械规则 |
| FVG | Fair Value Gap；常按三根K线之间的不平衡区观察 | 不是所有跳空、交易时段缺口或换月缺口都等同该模型 |
| iFVG / IFVG | 原FVG被穿越后，作者观察其可能转为反向作用区 | 被穿越不是自动有效，仍要结合方向与后续反应 |
| BISI / SIBI | 分别指偏多与偏空方向的不平衡区域标记 | 色块与缩写不能代替具体上下沿与确认条件 |
| OB / BB | Order Block / Breaker Block，作者标注的结构区域 | 选哪根K线、是否有效必须回看原图，不由编辑另创判定法 |
| BPR | Balanced Price Range，作者讨论的相向不平衡区域重叠 | 重叠区并不是必有支撑或阻力的保证 |
| Premium / Discount | 相对选定区间中点的上半区 / 下半区 | 测量高低点选择会改变划分，不等于资产客观昂贵或便宜 |
| TP / SL / BE | 止盈 / 止损 / 保本退出或保护 | 计划订单、已执行订单及最后结果需要分别记录 |
| FOMO | 害怕错过而追入的心理 | 他人聊天的FOMO或梭哈表达不能写成作者要求 |

## 图表、字幕与数字怎么核对

每篇“来源原文”保留作者原话，“中文整理”和“配图细读”属于编辑说明。作者答复中包含他人问题时，先看发言者与来源链接。截图中的浮盈、平台榜单、模拟回放和实际账户净收益是不同信息，不能互换。

视频附本地媒体、时间戳字幕、分段讲解与关键帧。来源字幕可能是自动字幕；本地机器转写保留原稿与修订稿。术语、数字、品种或口述与画面冲突的位置会留说明，全文读过字幕不等于逐秒人工听完整音轨。低清看不清的价位不补造。
