# 个人学习路径不普适与ICT加PA的自我归纳

发布时间：2026-10-31 23:19:47（北京时间）｜类型：交易经验

## 来源原文

每天后台会有很多重复的问题
问这些问题我能理解你，但是我不会回答你
我现在告诉你原因，自己去找答案

第一，看视频不认真
第二，实盘经验不够

认真看了但还是不明白
说明实盘经验不够
理论无法指导实践

当然如果是有价值的问题
我会非常详细的解答
因为解答也是对我现有体系的梳理
对我自己的帮助会比提问者更大

其次学习路径
我的路径没有普适性
你按我的路径来，会被打的很惨

因为我走了很多弯路
交了很多学费才慢慢形成了自己的风格

但是这些弯路也是必须要经历的
不然我也不会总结出现在的体系
我现在能做日内，能做波段，也能做趋势
我能持仓几个小时，也能持仓几十天

理论我已经说了，ICT+PA
有人说内容太多了，看不过来不知道从哪里开始看

这就对了，内容多是在检验你有没有时间，也是在检验你有没有总结归纳能力

能过这两关，恭喜你，你不用看我的东西了，你会形成自己的风格，会比我做的更好

## 中文整理与学习要点（编辑）

作者解释为何不反复回答视频里已有的问题：先认真看，再用实际经验验证；有价值的问题能帮助他梳理体系。其学习路径有许多弯路和费用，不能直接复制为所有人的最短路线。
作者称可做日内、波段与趋势，持仓从数小时到数十天，理论组合为ICT+PA；大量内容也在考验时间投入和归纳能力。此为作者自述能力，不代表各种持仓期限已有独立绩效验证。
原文理论无法指导实践是其强调经验的表述，整理不应反向鼓励没有规则就实盘；应逐段保存方法、问题和实际反馈。
