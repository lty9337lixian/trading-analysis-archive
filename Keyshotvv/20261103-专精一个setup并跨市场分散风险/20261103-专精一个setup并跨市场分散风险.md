# 专精一个setup并跨市场分散风险

发布时间：2026-11-03 15:15:47（北京时间）｜类型：基础教学

## 来源原文

我这套体系只适合不同市场不同品种的交易

举几个例子
ES+NQ是不同品种同市场
EU+BTC是不同品种不同市场
农产品+化工+金属是不同品种不同市场

要避免在同市场中多品种持仓
因为几乎都是同质性交易，变相增加仓位风险

一定要避免专精一个品种（很反直觉对吧？）
以免陷进去，产生执念，进而怀疑自己
一定要专精一个SETUP
所以很适合进行不同品种不同市场的多笔持仓

其次级别不能小
外盘1H起步上到日线，5M+15M pass
内盘15M起步上到周线，1M+5M pass

所以你会看到我手上会有很多持仓
但是风险小，盈亏比合适
人也不会太累

## 中文整理与学习要点（编辑）

作者明确说明这阶段方法适合不同市场、不同品种反复找同一个setup。ES与NQ属于同市场多品种，EU与BTC、农产品与化工与金属则被他视为不同市场。避免同市场多品种同向持仓，因为可能只是变相加仓。
他鼓励专精setup，避免执着单一品种；周期下限为外盘1H到日线，排除5M/15M，内盘15M到周线，排除1M/5M。这是此时公开的规则，与早期小周期案例不能拼成同时不变的要求。
跨市场并不自动消除相关性，原文未给合计风险上限或相关系数；作者说风险小、盈亏比合适为自评，不能代替账户层面验证。
