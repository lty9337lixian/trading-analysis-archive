# 整体对上周短线做个复盘

## 原帖正文

整体对上周短线做个复盘 上周整体交易表现不理想。期货（黄金、纳指）与加密山寨币均出现明显失误，根源在于主观偏见过重、震荡行情没有及时切换到大周期视角，以及做山寨时忽视 BTC 大盘优先级；但依托 BTC 强弱筛选强势山寨这套底层思路本身是成立的，只是存在提前入场的执行错误。 

一、期货端（黄金、纳指）核心问题

 上周黄金、纳指交易效果很差，两大主要问题： 市场进入震荡行情时，本应切换视角，优先看更高周期的关键价位，我没有及时转变交易思路。主观偏见过重，亏损之后持续在小级别反复拉扯、频繁操作。 交易的正确逻辑是：等待市场走出信号，行情怎么走，我们再跟随。习惯提前预判、提前挂单入场。本质是预设行情会按照自己的想法运行，试图主导市场，而不是跟随市场客观盘面。 教训：一切以客观盘面为准，多耐心等待，减少预判式提前进场。 

二、加密市场（山寨币）核心问题

 核心原则：山寨币交易必须以比特币（大盘）为基准。上周加密板块整体做得一般，期货、山寨都有失误。 绝大多数标的不能逆 BTC 大盘去交易；只有极少数独立行情妖币除外，不能当作常态。 若 BTC 和山寨的盘面结构、行情判断出现冲突，优先采信比特币的信号。 本轮 BTC 下行，SOL 同步大幅下跌，但以太、GUP、CRV 抗跌表现很强；后续 BTC 反弹，这些币种涨幅遥遥领先，证明这套筛选逻辑没问题。 ✅ 做得对的地方：通过 BTC 下跌阶段去筛选强势山寨的思路有效。 大盘平稳阶段看起来漂亮的结构，在 BTC 下跌时很容易被证伪，只是虚的泡沫。 ❌ 重大失误：下跌途中提前抄底 TAO、STX。当时错误用山寨自身结构盖过了 BTC 大盘结构，在 BTC 下跌过程中提前接货。 一个山寨的结构好不好，不能只看 BTC 平稳时期的形态；只有在 BTC 真正大幅下跌的压力测试下，能够稳住价格、守住结构，才是真实的强势。 

三、提炼两条交易指导原则

 避免在同一价位反复进场出场，持续磨损本金。 日内期货交易流程先在大周期确定市场偏见、结构方向，标记关键位置并设置警报；再下沉到小级别，等待盘面事件触发，做右侧交易。 BTC 与山寨结论冲突时，以 BTC 判断为准。 加密市场交易流程以比特币为核心锚。等待 BTC 出现明确行情事件、到达目标价位或者企稳后，再寻找山寨机会；或者在 BTC 猛烈下跌阶段，从中筛选抗跌的强势山寨。 

小结

 但通过大盘压力测试筛选强势山寨的思路经过行情验证，后续需要遵守规则，等待右侧信号，杜绝提前抄底。上周的亏损，主要来自主观预判、震荡行情执着小级别博弈，以及山寨交易违背 BTC 优先原则。

## 学习要点（整理者）

**核心是纠正执行顺序：先看较大周期和BTC背景，等盘面事件出现，再决定小周期与山寨交易。**

### 1. 期货端：亏损后不要继续在同一价位来回折腾

作者承认黄金、纳指表现不理想：主观预判较重，震荡行情没有及时转向较大周期，亏损后又在小级别反复进出。其改进流程是：先确定大周期结构与方向倾向，标记关键位置并设警报，再等小级别盘面事件出现后做右侧交易。这里的方向倾向应随盘面调整，不能变成必须证明自己正确的执念。

### 2. 山寨端：先处理BTC与山寨结论冲突

作者认为多数山寨不能脱离BTC背景交易，极少数独立行情不是常态。TAO、STX的教训是：看到山寨局部形态就提前接货，忽略BTC仍在下跌。按他的修正，应等BTC出现明确事件、到达目标位置或企稳，再寻找山寨机会；下跌阶段也可先观察哪些山寨抗跌，但**观察候选不等于马上买入**。

### 3. 抗跌筛选与入场时机要分开

作者以BTC下行、SOL走弱、以太等标的相对抗跌及随后反弹作为自己筛选思路的支持。学习时应分别记录“筛选理由”和“入场信号”：前者用于建立候选池，后者用于决定何时承担风险。单轮行情不能证明长期有效；“逻辑成立、经过验证”保留为作者自评。

### 4. 初学者复盘表

| 检查项 | 应记录的内容 |
| --- | --- |
| 大背景 | 当前偏趋势还是震荡？依据哪一级别、哪些高低点？ |
| 位置 | 关键区间在哪里？警报触发后具体要观察什么？ |
| 事件 | 什么盘面变化才允许入场？当前是否只是在猜？ |
| BTC约束 | BTC与山寨是否冲突？抗跌是观察结果还是未经考验的形态？ |
| 执行偏差 | 是否同一价位反复进出？是否亏损后增加操作？ |
| 事后验证 | 当时计划、实际操作和最终结果分开记录，保留失败样本。 |
