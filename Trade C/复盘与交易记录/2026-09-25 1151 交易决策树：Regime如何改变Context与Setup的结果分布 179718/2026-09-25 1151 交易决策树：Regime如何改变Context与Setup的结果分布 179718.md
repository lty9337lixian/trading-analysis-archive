# 交易决策树：Regime如何改变Context与Setup的结果分布

## 整理要点

作者将交易比作决策树，强调同样的Context和Setup在不同Regime下结果分布可能不同；原帖未提供统计样本与胜率数据。

## 作者原文

如果你阅读了我那个文档，就会发现：我们每一次交易，实际上是在进行一次决策树。

不同Regime下对应的Context和Setup是完全不同的。

即使是相同的Context和Setup，在不同Regime下，你进行决策的后果也是完全不一样的，你的结果分布也是完全不同的。

而你每一笔交易的核心，实际上就在于你具体的Context和Setup。
