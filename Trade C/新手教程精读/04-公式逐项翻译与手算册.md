# 公式逐项翻译与手算册

返回[[交易技术分析/Trade C/新手教程精读/00-新手教程学习入口]]。以下是整理者补充讲解，原式见逐节精读与原始PDF。**所有行情、账户和成本数字均为教学例，不是交易建议或作者实盘业绩。**

## 1. 先分清四种“公式”

| 类型 | 原文例子 | 应怎样读 |
|---|---|---|
| 可以算的定义或记账式 | 胜率、回撤、净值收支 | 先统一口径和单位，再代数 |
| 带假设的资金模型 | Equity下一步=Equity×(1+fR) | 先核对无外部收支、成本口径等条件 |
| 概率与期望表达 | P(R｜Setup)、E(R｜Setup) | 说明要研究什么，数值需要样本估计 |
| 流程或概念示意 | Edge×Execution×Survival、箭头链 | 说明相互关系，不能用主观打分算财富 |

看到等号并不意味着它一定是严格数学定义。比如动能第一篇写乘号、第二篇写加号，两处均未定义数值、权重与单位，所以不能当指标算法。

## 2. 符号逐字读

| 符号/词 | 白话 | 常见错误 |
|---|---|---|
| t、t+1、t+h | 现在、下一步、h步以后 | 一步不一定一天，也可能一笔交易 |
| P(A) | A发生的概率 | 概率不是一次结果保证 |
| P(A \| B) | 已知B时，A的概率 | 竖线不是除号 |
| E(X) | X按概率加权后的平均值 | 不是每笔实际得到的X |
| E(X \| B) | 筛出B条件之后的平均值 | 条件样本不能混进别的规则 |
| >、<、≤、≠、≈ | 大于、小于、不超过、不等于、约等于 | 计划不超过≠实际保证不超过 |
| Δ | 变化量 | 变化量不一定来自交易盈利 |
| ∑ | 把多项加起来 | 不是乘号 |
| log | 对数，复利中把连乘改写为求和 | 这里只在增长因子为正时可用 |
| f(变量…) | 一个依赖这些变量的函数 | 函数f与风险比例f是不同用法 |
| ↑、↓、→ | 增加、减少、流程或关系方向 | 通常没有提供具体幅度或算法 |
| Avg | 平均 | 计划目标不能冒充已实现平均盈利 |
| Net / Gross | 净额 / 毛额 | 已扣成本的数据不要重复扣 |
| oz | 盎司；合约规格中的贵金属使用金衡盎司 | 每盎司价格差不等于每手盈亏 |

### 特别注意R的三种语境

- `r_{t+1}`在趋势讨论中通常是未来价格收益率，比如价格100到102对应2%。
- `P(R｜Setup)`中的R可以泛指未来收益随机变量，原文没有处处声明单位。
- `1R=500美元`是风险金额；`这笔+2R`是结果相对该初始风险的倍数。原文`E(R)=0.4R`意指平均结果0.4个风险单位。

为了算清楚，本册把**初始风险金额记为B**，把**结果倍数记为m**，风险比例记为f。这样不会把500美元与2倍当成同一种量。

## 3. 条件概率：竖线后面是筛选条件

原文：`P(R未来｜S现在=X) ≠ P(R未来)`。

逐字翻译：只看符合X条件的时刻，后面的结果分布，可能与不筛选时不同。

教学数据：全体200次观察中，上涨100次，比例50%；其中40次符合X，上涨24次，比例60%。估计值分别是100/200与24/40。不能把“60%”说成下一次必涨，也不能仅凭40个样本断言存在稳定差异。样本是否独立、筛选是否看了未来、统计不确定性，都需要检查。

**分布不同不等于赚钱：**若上涨时只赚1、下跌时亏3，即使上涨概率60%，平均仍是0.6×1−0.4×3=−0.6。

`P(假设｜新证据)`只是在提醒你随证据更新判断。本书没有给出贝叶斯先验、似然或可直接计算的模型，不需要凭空捏造一个“当前成功概率”。

## 4. 胜率与平均盈亏：先用100笔看懂

原文胜率：

$$胜率=盈利笔数/总笔数$$

100笔中35笔盈利，胜率=35/100=35%=0.35。若另有5笔打平，亏损笔数就是60，不能仍把亏损率写65%。

原文期望（亏损幅度取正值）：

$$E=p_W\times\overline{W}-p_L\times\overline{L}$$

| 参数 | 原文例子 | 含义 |
|---|---:|---|
| pW | 0.35 | 盈利概率35% |
| 平均W | 3R | 盈利笔平均赚3个初始风险单位 |
| pL | 0.65 | 亏损概率65%，此例没有打平 |
| 平均L | 1R | 亏损笔平均损失1个初始风险单位 |

逐步算：0.35×3=1.05；0.65×1=0.65；1.05−0.65=0.40R。

想成100笔：赚35×3=105R，亏65×1=65R，净40R，除100得到0.4R。这是分布假设下的期望，不是承诺实际100笔恰好净赚40R。

### 高胜率为什么仍亏

原文80%赢1、20%亏10：80−200=−120，平均−1.2。即使多数时间都赢，少数大亏也能吞掉全部。

### 成本怎样放进来

若上述0.4R是**毛期望**，平均成本0.1R，则净期望0.3R。若盈利与亏损样本已按真实成交和费用计算为净R，直接求平均，**不再减0.1R**。

价差和滑点若已体现在实际进出价格中，不能又完整加扣一遍。无成本数据时应明确“毛结果”，不能标成净优势。

### 盈亏平衡胜率（整理者推导）

假设只有赢/输两种结果，赢W、输L、每笔额外成本c，且均用同一单位：

$$E=pW-(1-p)L-c$$

令E=0，移项得到：

$$p_{平衡}=\frac{L+c}{W+L}$$

W=3、L=1、c=0时为25%；c=0.1时为27.5%。实际存在打平、变动成本与不同退出方式时，应使用完整净结果分布。

## 5. 仓位手算：先算可能损失，再算手数

对应PDF第19页：账户100000、风险0.5%、价格止损距离5美元/盎司。

**第一步，预算金额：**100000×0.005=500美元。0.5%=0.005，不是0.5。

**第二步，确定合约单位：**黄金报价每盎司涨跌1美元，整手盈亏还要乘该手包含的盎司数。CME资料列标准GC为100金衡盎司，微型MGC为10金衡盎司；这是合约规模，不能移植到券商XAUUSD/CFD的“手”。[CME黄金产品概览](https://www.cmegroup.com/education/lessons/product-gold)。查阅日2026-10-22。

**第三步，计算每手计划价格风险：**

$$每手价格风险=|入场价-止损价|\times合约乘数$$

| 演算品种 | 距离 | 乘数 | 每手价格风险 | 500美元预算下未计成本手数 |
|---|---:|---:|---:|---:|
| GC | 5美元/盎司 | 100盎司/手 | 500美元/手 | 1手 |
| MGC | 5美元/盎司 | 10盎司/手 | 50美元/手 | 10手 |

注意单位相消：`美元/盎司 × 盎司/手 = 美元/手`。

**第四步，加成本与执行缓冲：**若教学假设每手MGC另留5美元总成本/滑点缓冲，则每手55美元。500/55=9.09，不能下9.09手的整数合约，向下取整为9手；计划总额9×55=495美元。10手则550，超预算。5美元只是本例假设，未声称是真实收费，也不保证极端滑点不会超过它。

$$手数=\left\lfloor\frac{账户净值\times风险比例}{价格距离\times每手乘数+每手成本缓冲}\right\rfloor$$

该式假设成本可按手近似线性分摊。若有最低收费、复杂多腿、非线性期权、加减仓，需另建模型。还要通过可用保证金、组合风险和最小单位限制。公式算出0手时，答案是当前条件下不做，并非把止损硬挪近以凑1手。

**止损预算不是保险合同。**触发与实际成交可能不同。Investor.gov的股票订单教育说明指出止损触发价不保证成交价，止损限价又可能不成交；这一机制提醒不能代替具体期货订单规则核对。[订单类型说明](https://www.investor.gov/introduction-investing/investing-basics/how-stock-markets-work/types-orders)。

## 6. 1R与收益倍数：分母固定在事前

$$m=本笔净盈亏/B$$

B=100美元：净赚250→m=+2.5；净亏130→m=−1.3。超过−1R是可能的，不能在统计时强制改成−1。

移动止损后，初始B仍保留，不能为了展示“高盈亏比”重新缩分母。计划奖励/风险比与最后实际结果也不同：目标300、计划亏100是计划3:1，不代表实际平均盈利3R。

## 7. MAE与MFE：中途经历了什么

不加减仓的多头示例：100入场，初始止损95，持仓期间最低97、最高108、105退出。

- 价格MAE=max(0,100−97)=3。
- 价格MFE=max(0,108−100)=8。
- 价格毛盈亏=105−100=5。
- 初始距离5，则分别为0.6R、1.6R、+1R，暂不含费用。

空头100入场，期间最高103、最低92、95退出，MAE=3、MFE=8、毛收益=5，方向要反过来。入场之前或离场之后的高低不计入。若同一根K线含入场前数据，不能直接拿该根完整高低作为持仓期间极值。

MFE告诉你曾浮盈到哪里，不能证明你能事前精准在最高点卖出。优化止盈应使用多笔与样本外检验，不能只追求吃满历史极值。

## 8. 净值与收支：一次只记一次

简化净值：现金余额+尚未计入现金的未实现盈亏。期货结算会改变各项分类，按报表口径，防止重复加已结算盈亏。

$$期末净值=期初净值+毛交易盈亏-成本-提款+入金$$

10000+300−40−500+1000=10760。

这里净交易利润260，外部现金净流入500，账户增加760。不能报告为交易赚7.6%。如果300本来已经是净利润，不应再减40。

净值、保证金和名义敞口是三件事：保证金是履约资金安排，名义敞口取决于价格与合约规模；保证金低不意味着风险低。教程未提供当前保证金数额，本册也不填一个可能过期的数。

## 9. 回撤与回本：分母为什么不同

$$DD=(历史最高净值-当前净值)/历史最高净值$$

12000峰值降到9000：下降3000，相对12000是25%。恢复需要赚3000，相对剩余9000是33.33%。

设原来1元、亏损比例d，剩1−d。回本所需收益率：

$$恢复收益率=\frac{1}{1-d}-1=\frac{d}{1-d}$$

| 下跌比例 | 剩余本金比例 | 回本所需涨幅 |
|---:|---:|---:|
| 10% | 90% | 11.11% |
| 20% | 80% | 25% |
| 25% | 75% | 33.33% |
| 50% | 50% | 100% |
| 80% | 20% | 400% |

d达到100%时分母为0，不能靠原账户剩余资本自然回本。最大回撤是整条净值路径中DD的最大值，历史最大值不是未来保证上限。提款与入金需另记，否则资金曲线回撤与策略表现会混淆。

## 10. 复利：不用对数也能先算懂

原文：`Equity下一步=Equity当前×(1+fR当前)`。

本册改写为：

$$Q_{t+1}=Q_t(1+f m_t)$$

Q是账户净值，f是初始风险占当前净值的比例，m是本笔净结果倍数。假设每笔按当时净值设风险，成本已经包含，无外部收支。

| 步骤 | 净值 | f | 初始风险金额 | 结果 | 新净值 |
|---|---:|---:|---:|---:|---:|
| 第1笔 | 10000 | 1% | 100 | +2R | 10200 |
| 第2笔 | 10200 | 1% | 102 | −1R | 10098 |

总增长因子=1.02×0.99=1.0098，即增长0.98%，不是简单2%−1%=1%。

### ∑log到底在干什么

多笔净值是初始净值乘上每一笔的增长因子。对数有“乘积变加法”的性质：

$$\log(Q_n/Q_0)=\sum_{t=0}^{n-1}\log(1+f m_t)$$

不懂log时先逐笔相乘即可。这里采用自然对数讨论增长；任何因子≤0时，不能继续使用这个对数模型，经济上也可能意味着资本耗尽或负债。

### 正期望为何仍可能越做越少

假设每笔独立、50%赚2R、50%亏1R，分布保持不变：算术期望=0.5×2−0.5×1=+0.5R。

- f=10%时，一赢一亏的增长因子=1.2×0.9=1.08，增长8%。
- f=60%时，一赢一亏=2.2×0.4=0.88，反而损失12%。

在这个**教学分布**下，60%风险比例即使算术期望为正，平均对数增长却为负；长期典型路径会受损。不能从本例推出10%是安全或推荐比例，它同样可能造成巨大回撤。本例只是证明仓位会改变复利结果。

### 对“顺序风险”的一个精确补充

若f固定、每笔R列表固定、无提款入金、无停手和保证金约束，增长因子相乘满足交换律，改变顺序不改变最终乘积。但中途最大回撤、触及停止线的机会、提款能力和心理压力仍可能改变；真实交易还会改变仓位或受强平约束。所以不要笼统说“相同固定比例结果只换顺序就必然改变终值”。

## 11. 原文未展开的增长指标

**CAGR（整理者补充）：**无外部现金流、起终值为正，经过y年：

$$CAGR=(期末/期初)^{1/y}-1$$

10000两年变12100，CAGR=√1.21−1=10%，而不是总21%直接除2得到10.5%。中间有入金提款时，不能直接用这条简式当策略年化收益；需采用适当现金流调整方法。

**资本效率、破产概率、预期回撤分布：**原文只提出需要关注，未给出统一算法或足够参数。不能凭这一教程自动计算，更不能随便填上精确数。

## 12. 纪律百分比：先明确分母

原文例：100个信号，执行96个，其中94个符合仓位规则。

- 信号执行率=96/100=96%。
- 已执行中的风险合规率=94/96≈97.92%。
- 相对全部信号的风险合规执行覆盖=94/100=94%。

三者都能计算，但名称必须明确。另记系统外额外交易、漏做和重大超仓，避免漂亮百分比掩盖风险。

## 13. 全文概念式与关系式速查

| 原文表达家族 | 对应白话 | 是否可直接代数 |
|---|---|---|
| Information→Belief→Action→Risk→Outcome | 信息变成判断，再作行动并接受结果 | 流程；风险预算应在行动前制定 |
| Belief→Positioning→Orders→Transactions→Price | 观点通过持仓和订单参与定价 | 解释机制，非必然单向过程 |
| Kline=Compressed Outcome；Kline≠Market | K线压缩记录，不等于全部市场信息 | 概念 |
| State=(Trend,Volatility,…) | 状态是一组观测变量 | 向量清单，未给估计模型 |
| Trend=Trend(Timeframe) | 趋势与周期有关 | 依赖关系 |
| Momentum=方向×速度×持续性 / 三者相加 | 动能至少拆三个维度 | 概念，两式不可直接混算 |
| Price>Previous High | 价格超过预先定义的前高 | 可检查事件，非盈利条件 |
| Level→Expected Order Flow | 参考区域可能改变订单行为 | 机制假设 |
| Break→Response；Probe→Failure to Accept | 越界看后续；试探后未站稳 | 过程判断，需定义时间与阈值 |
| Pullback≠Reversal；Old Trend Fails→Opposite Persistence | 回调不自动等于反转，反向持续性另确认 | 分类框架 |
| Bias≠Position；Long Bias≠Long Entry | 看多不等于持有或立即买入 | 概念 |
| Setup=Why；Trigger=Why Now | 机会理由与执行时机分开 | 概念 |
| Loss≤Risk Budget；Position Size↓ | 预算限制计划风险，距离大就缩数量 | 约束目标，非成交保险 |
| Liquidity↑⇒Market Impact↓ | 承接更好通常减少冲击 | 需控制其他条件，非精确函数 |
| Probability×Magnitude；风险≠波动 | 看发生概率及损害，不只看波幅 | 简化风险框架 |
| Backtest Profit≠Statistical Edge | 回测盈利不等于经验证优势 | 证据边界 |
| Action Quality≠Outcome；Action≈Policy | 结果不等于决策质量，执行应按规则 | 需定义评分和分母 |
| ΔEquity=Edge×Exposure×Execution−Costs | 增长受优势、规模、执行及成本影响 | **不是会计恒等式** |
| Wealth/资本系统的六项相乘 | 各环节共同限制长期表现 | **没有可直接代入的数值单位** |
| EquityCurve=f(…) | 曲线受多个因素共同影响 | 没给具体函数 |
| E(R｜trade)<Threshold；EntryThreshold↓ | 不够条件仍交易、情绪降低标准 | 门槛须事前定义，未给通用值 |
| Current Equity<Reference Equity | 当前资金低于心理参照点 | 只描述情境，不必然导致报复交易 |
| No Trade也是Capital Allocation | 等待保留风险容量 | 不表示现金完全无风险 |
| Uncertainty→Emotion→Policy Adherence | 不确定激发情绪，仍要检查行为规则 | 心理工作框架 |

## 14. 最先练熟的五件事

1. 把百分比转小数，0.5%写0.005。
2. 分清价格距离、合约乘数、每手损失、风险预算。
3. 用初始风险金额计算净R倍数。
4. 从真实净结果算期望，不用计划目标冒充平均收益。
5. 用历史峰值算回撤，用剩余本金算恢复收益率。
