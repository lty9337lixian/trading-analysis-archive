# 术语与易混概念速查

返回[[交易技术分析/Trade C/新手教程精读/00-新手教程学习入口]]。这里是阅读翻译表，不是所有交易流派都共同采用的统一定义。

## 市场与读图

| 词 | 白话 | 不要混淆 |
|---|---|---|
| Price | 此刻成交价格 | 不等于所有人的共同估值 |
| Marginal | 边际，即正在促成新增交换的那部分力量 | 不代表平均所有持仓 |
| OHLC | 开盘、最高、最低、收盘 | 不包含完整先后路径 |
| Timeframe | 观察周期 | 5分钟和1小时方向可相反 |
| State | 当前多项变量组成的状态 | 不等于一句看多 |
| Regime | 持续一段时间的环境类型 | 不一定能实时完美识别 |
| Trend | 某尺度上持续方向性 | 允许逆向波动 |
| HH/HL | 更高高点/更高低点 | 是识别代理，拐点规则须定义 |
| Proxy | 可观察的替代指标 | 不等于对象本身 |
| Range | 反复在区间内波动的状态 | 不保证边界永不失守 |
| Mean Reversion | 向参考中心或区域回归的倾向 | 不是无条件回本 |
| Volatility | 变化的离散或波动特征 | 不直接指方向 |
| Momentum | 方向移动的速度与持续性等 | 本书未给唯一计算式 |
| ROC | 变化率 | 要说明窗口长度 |
| ATR | 平均真实波幅 | 不等同收益率标准差或方向信号 |
| Close Location | 收盘在该根高低范围中的位置 | 不直接保证下一根延续 |
| Liquidity | 吸收交易量而不显著冲击价格的能力 | “某处有止损单”只是另一类推测 |
| Order Flow | 订单与成交的流动过程 | 单凭K线不能完整重建 |
| Focal Point | 多方可能共同关注的参考点 | 不是必然支撑 |
| Key Level | 可能影响行为的参考价格区 | 多画线不能自动提高优势 |
| Breakout | 越过预先定义边界 | 不等于站稳 |
| Acceptance | 在新区域持续交易的操作性判断 | 需要事前规定代理标准 |
| Rejection | 探索后无法维持并退回 | 长影线只是可能代理 |
| Sweep | 短暂越过参考高低点 | 不证明知道隐藏止损位置 |
| Reclaim | 回到参考位的指定一侧 | 如何确认须事前定义 |
| Pullback | 主方向中的暂时逆向运动 | 不同于账户Drawdown |
| Reversal | 原方向失效并形成相反持续性 | 旧趋势失效后也可能震荡 |

## 从判断到订单

| 词 | 白话 | 要回答的问题 |
|---|---|---|
| Bias | 方向倾向 | 我目前偏向哪边？ |
| Context | 影响机会意义的背景 | 发生在什么环境？ |
| Setup | 事前识别的机会条件组合 | 为什么值得开始寻找交易？ |
| Signal / Trigger | 本书语境下的执行触发事件 | 为什么是现在？ |
| Trade Hypothesis | 可被推翻的交易预案 | 期待什么，什么会证明依据失效？ |
| Entry | 实际开始承担持仓风险 | 何时、何价、如何成交？ |
| Invalidation | 原假设不再成立 | 持仓理由是否还在？ |
| Stop Loss | 实施损失控制的机制 | 怎样退出或限制损害？ |
| Position Size | 持仓数量与风险敞口 | 该判断影响账户多大？ |
| Exposure | 资金或风险暴露 | 承担了什么方向、规模的风险？ |
| Exit | 退出规则 | 正确、错误或超时分别怎样结束？ |
| Policy | 事前决策规则 | 同样条件下是否按同一标准做？ |
| Threshold | 最低参与门槛 | 条件和净价值是否足够？ |
| Confirmation Bias | 只找支持既有观点的证据 | 是否忽略反证？ |

## 统计、资本与执行

| 词 | 白话 | 必要补充 |
|---|---|---|
| Edge | 成本后有证据支持的有利条件 | 不等于看图准确率 |
| Expectancy | 结果的概率加权平均 | 不保证单笔或固定笔数盈利 |
| Distribution | 所有结果的幅度和频率 | 平均值不能替代整个分布 |
| Variance | 结果围绕平均值的离散程度 | 不等同策略必然失效 |
| Median | 排序后的中间值 | 可与均值明显不同 |
| Skew / Kurtosis | 不对称性 / 与尾部等相关的形状特征 | 初学可先关注真实极端亏损 |
| In-sample | 参与研究或调参的数据 | 漂亮表现可能过拟合 |
| Out-of-sample | 未用于该轮调参的验证数据 | 用它继续调参后，不再是干净保留集 |
| Fitted Noise | 把噪声拟合成规律 | 多试参数后只报赢家会放大问题 |
| Fees / Spread / Slippage | 显性费用 / 买卖价差 / 预期与实际成交偏差 | 已在成交价中体现的不要重复扣 |
| 1R | 事前风险金额单位 | 结果倍数的分母固定 |
| MAE / MFE | 持仓期最大不利/有利运动 | 不含离场后行情 |
| Equity | 包括持仓损益的账户价值 | 不等于可开仓额度 |
| Margin | 保证金 | 不等于最大亏损 |
| Initial / Maintenance Margin | 初始/维持保证金 | 真实要求需查当前市场及经纪商规则 |
| Variation Margin | 随结算变动的保证金收付 | 避免将已结算损益重复计算 |
| Buying Power | 经纪商口径的可用购买/交易能力 | 不等于个人可承受风险 |
| Drawdown | 从历史净值峰值下降 | 与价格Pullback分开 |
| Risk of Ruin | 不能继续运行的概率 | 先定义阈值与时间范围 |
| Compounding | 收益/损失基数随资本变化 | 有增长也有收缩 |
| CAGR | 多年折合复合年增长率 | 简式要求无外部收支等条件 |
| Capital Efficiency | 资金占用和产出的关系 | 本书未给唯一指标口径 |
| Correlation | 多个结果一起变化的程度 | 多品种不自动等于分散风险 |
| Tail Risk | 罕见但严重的损害 | 历史未出现不代表不存在 |
| Model Risk | 所用假设或关系不适用的风险 | 不用“相信系统”掩盖 |
| Sequence Risk | 路径影响生存、限制与现金需要 | 固定比例无约束终值有交换律特例 |
| Adherence | 对规则的遵守程度 | 要定义分母并单列重大违规 |
| FOMO | 怕错过导致标准漂移 | 情绪存在与行为违规分开 |
| Revenge Trading | 为回本改变正常风险政策 | 盈利也不使违规变正确 |

## 三组最容易误会的对照

**逻辑失效、执行止损、账户预算：**第一项管理由，第二项管行动，第三项管最多计划承担多大损害。三个都要写，不是只在图上画一根线。

**价格收益、R倍数、账户收益：**价格涨1%不等于账户涨1%；+1R不等于+1%。在本册简化模型里，账户收益约为风险比例f乘结果倍数m。

**原文观点、教学示例、验证事实：**原文说明定义和框架；精读增加理解例子；真正有效性必须有数据支持。例子算术正确不等于策略已经有效。
