## 一条贯穿七课的学习路线

**背景 → 位置 → 形态／信号 → 确认 → 目标与失效条件 → 按新证据更新。**

这条路线是整理者归纳，帮助组织课程，不是作者逐字列出的统一公式。不要跳过前半段，只寻找一根“好 K 线”。

## 常用术语速查

| 术语 | 初学者理解 |
| --- | --- |
| 多头／空头 | 本文分别指看涨／看跌方向的参与或分析视角；不是两个统一行动的实体。 |
| 跟随 | 信号之后是否持续支持原方向，需要看后续走势。 |
| 两腿 | 两段同向推进，中间有反向调整；不等于两根 K。 |
| Setup | 背景、位置与形态等条件组成的交易结构。 |
| EMA | 指数移动平均线；课程多次提到 20 周期均线，具体设置仍需核对视频。 |
| Stop 入场 | 达到触发条件后入场的语境；和用于退出的保护性止损分开理解。 |
| AB=CD／MM | 等距投射／测量目标的课程语境；需要明确锚点与实体、影线口径。 |
| TTR | 窄幅震荡区间，常伴随密集重叠与有限推进空间。 |
| MTR | 主要趋势反转结构的课程语境；可能先进入区间，不保证大反转。 |
| 缺口 | 本作者包含自行定义的突破型、信号 K 等口径，不能一律等同隔夜跳空。 |

## 标注怎么读

- **加粗**：需要记住的区别或条件。
- <mark>高亮</mark>：容易误用的关键结论。
- 提示块：核心摘要、证据边界或学习建议。
- “整理者示例／练习”：为帮助理解新增的内容，不冒充视频原话。
- “待回看”：现有字幕不足以确认，不能当已核验规则。
