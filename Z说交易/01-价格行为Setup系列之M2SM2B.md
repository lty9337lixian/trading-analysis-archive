## 初学者详细学习笔记

> [!abstract] 先记住这一句话
> **M2B/M2S 是趋势背景下，价格经过两段回调或反弹，在均线附近寻找第二次恢复趋势尝试的入场结构。** 它的关键是背景、位置与确认共同成立，不能只凭数到“两腿”就入场。

### 1. 本课解决什么问题

作者用黄金五分钟图讲解两类顺势 setup，并串联当天从弱上涨到震荡的变化。学习重点有两层：先认识 M2B/M2S，再理解为什么同一个结构在不同背景下不应采用同一种目标和持仓方式。

**本篇字幕没有时间戳。** 以下回查位置按原有字幕小标题定位；具体 K 线、入场价与止损价必须配合上方视频看，不能从“这里”“这根”还原。

### 2. 先认识这些词

| 词语 | 在本课中的理解 |
| --- | --- |
| Setup | 一组交易条件的组合，包含背景、位置及形态，不是单独一根 K 线。 |
| 回调／反弹 | 上涨中的向下调整／下跌中的向上调整；局部方向与较大的趋势方向相反。 |
| 两腿 | 一次调整推进，中间有反向尝试，再出现第二段调整。不能简单理解为两根 K 线。 |
| 高二／低二 | 恢复上涨／恢复下跌的第二次尝试。这里采用初学者概念说明，具体计数必须结合图形。 |
| EMA 附近 | 课程多次提到的均线观察位置；字幕将其误识别为“烟梅、页眉、耶眉”等。 |
| 跟随 | 信号之后的价格行为是否继续支持该方向；不是只看信号当时好不好看。 |

“高二”不是“第二个更高的高点”，“低二”也不是“第二个更低的低点”。它们描述尝试的次序。

### 3. M2B：上涨背景中的两段回调

**对应原字幕：〈价格行为入门〉、〈实盘推演〉、〈策略总结〉。**

1. 先确认较大的上涨结构仍成立，而不是只盯最近几根阳线。
2. 价格开始向下回调，第一次恢复上涨的尝试未能持续。
3. 回调出现第二段，来到均线附近，最好同时有其他支撑或缺口位置。
4. 观察是否出现作者所说的高二及顺势信号，再考虑做多。
5. 入场后的目标取决于背景：强趋势可以研究波段延续，弱趋势则要注意前高附近的止盈与回补。

作者举过“阴线被强阳线反包，第一次上行又被压回，随后再出现恢复尝试”的例子。**学习其先后关系即可，不把所有阴阳线组合机械归类为 M2B。**

### 4. M2S：下跌背景中的两段反弹

逻辑与 M2B 对称：较大的下跌背景 → 向上反弹 → 恢复下跌的第一次尝试未持续 → 第二段反弹到均线附近 → 观察低二和空头信号。

课程强调它属于顺势策略。因此，<mark>必须先说清“顺的是哪一级别的趋势”</mark>。如果大背景仍向下，一个局部上涨通道可能只是反弹；不能因为局部有上涨形态就把它当成强多头趋势。

### 5. 为什么“阶梯模式”会影响目标

**对应原字幕：〈实盘推演〉中多次讨论缺口回补、宽通道。**

作者观察到，价格虽然持续抬高高低点，但每次突破留下的缺口很快回补，逆势空头也有获利或解套机会。这在他的框架里属于弱趋势、宽通道或阶梯模式的特征。

这意味着：

- **方向仍可偏上，但延续效率不足。** 创新高不等于一路上涨。
- 回调可能较深；用非常紧的止损追涨容易与实际波动冲突。
- 在前高或阻力区，不能想当然地期待继续大幅突破。
- 若缺口反复回补，同时不断回测前高前低，应重新考虑震荡背景。

“逆势方能赚钱”是作者根据价格路径进行的假设性分析，不是读取到了实际交易者账户。

### 6. 趋势转弱后，为什么要改变操作思路

作者接着讨论回调越来越深、接近重要低点，以及均线缺口 K 线和趋势线被破坏的情形。这些现象促使他考虑 MTR（主要趋势反转）或更大的震荡区间。

初学者应理解为：**原来支持顺势持仓的依据减少了，需要重新判断。** 不能把“MTR”理解成必然出现相反方向的大趋势。作者在案例中多次等待再次测试或二次入场，也会因为前一段太强而放弃第一次反向信号。

进入震荡背景后，他主要研究上沿附近的做空、下沿附近的做多，并警惕第二段走势看似强劲但突破失败。这里的边界来自图表，字幕不能提供精确价格。

### 7. 课中可复用的判断顺序

> [!tip] 整理者归纳：先完成这五个问题
> 1. 大背景是趋势、弱趋势，还是区间？
> 2. 两段调整分别在哪里？第二次尝试能否辨认？
> 3. 均线附近还叠加了什么位置依据？
> 4. 信号之后有没有确认？前一段逆势推进是否过强？
> 5. 最近的目标或障碍在哪里？原假设在什么位置失效？

这些问题是根据本课组织的学习清单，不是作者逐字给出的五步公式。

### 8. 最容易学错的地方

- **只数两腿，不看背景。** 这是作者结尾明确反对的机械用法。
- **把均线触碰当入场指令。** 均线只是位置条件，还要看结构与信号。
- **看到很强的一段走势就立即反做。** 课中多次要求等待二次机会。
- **把宽通道当成强趋势。** 缺口的回补、逆势推进能力同样要看。
- **用结果证明当时所有判断都正确。** 回放要停在信号当时，而不是看完结果再找理由。
