# Z说交易教学笔记

- 用户指定的专题目录，依据 Clippings 中 7 篇现有字幕整理；原文件保留，不自动移动或删除。
- 每课一篇，顺序为视频、初学者详细学习笔记、原字幕；属性仅 title/source/date，date 沿用源文件发布日期。
- 摘要忠实于字幕，作者经验、因果推测和未验证概率须明确归属。整理者新增解释与练习单独标示。
- 字幕里的图表指代、价格、测量锚点和歧义术语无法确认时注明待回看，不编造图表事实；原字幕逐字保留。
- 重点用加粗、mark 高亮和 Obsidian callout，不能只靠颜色表达含义。
- 完成后核对原字幕完整性、视频 ID、来源、时间定位、作者观点与整理者说明的边界；用户本次指定由独立 Agent 对照字幕审查，无需提交外部平台。
