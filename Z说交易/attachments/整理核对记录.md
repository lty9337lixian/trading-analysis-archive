## 内容核对的重点

| 课程 | 防止的主要误读／保留的不确定项 |
| --- | --- |
| M2B/M2S | 不将两腿等同两根 K；不只凭均线触碰入场；无时间戳，按源小标题定位。多空转写歧义不补成交易指令。 |
| 支撑阻力 | 静态／动态沿用作者口径；不把斜线理解为价格不变；GX、VR 等不明缩写不擅自扩写；概率不作统计。 |
| 缺口（一） | 区分突破识别与跟随强度；空头平仓为买、多头平仓为卖；长影线锚点前后口述不一，标记回看。 |
| 缺口（二） | 区分局部方向与强度；stop 入场不等于保护止损；“信念不等于扛单”；多周期口径不混用。 |
| 随机回放 | 保留等待、改变观点与事后才发现的目标，不美化成提前预测；不复用失效均线显示；不从口述生成完整绩效。 |
| 交易逻辑 | 信号止损与结构止损按假设区分；锚点排序字幕不清，不制造六种精确算法；独立算例明确非视频价格。 |
| 缺口（三） | 精准 MM 为作者命名；主导机构为推测；最后缺口的选取需画面；不把持有目标改成无条件扛单；心理经验不泛化。 |
