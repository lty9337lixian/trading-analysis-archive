# 线索C教学笔记规范

- 用户指定本目录保存线索c频道的逐课教学笔记，每个视频一篇 Markdown。
- 属性只保留 `title`、`source`、`date`；整理日期不得冒充发布日期。
- 正文先嵌入原视频，再放详细教学整理；使用加粗、彩色重点和 Obsidian 提示块。
- 根据实际取得的视频内容整理；区分课程观点与整理者的解释、练习和核验限制。
- 不将 AI 整理笔记标作完整字幕；不编造案例价格、时间点或胜率。

- 章节信息图使用 GPT 内置生图工具，保存于 `attachments/` 并在原视频之后嵌入；图示不代替正文条件。生成和修订提示词保存在附件目录的 JSON 文件中。
- 信息图交付前逐张核对文字、公式、箭头、支撑阻力位置及形态几何；止损调整要表达确认后的先后顺序。数值图无法保证比例时，改用概念示意与独立算例；修订后再次视觉检查并验证笔记引用。
